# Тестовый интерфейс v2

Откройте `index.html` через любой статический сервер. При первом запуске введите URL Supabase и publishable/anon key. Затем войдите пользователем Supabase Auth.

Для локального запуска из этой папки:

```powershell
python -m http.server 4173
```

Откройте `http://localhost:4173`. Старый проект не используется и не изменяется.
